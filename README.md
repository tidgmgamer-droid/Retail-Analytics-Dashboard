**RETAIL SALES ANALYTICS \& FORECASTING**   



**BUSINESS PROBLEM**

Analyzed retail transactions to uncover demographic purchasing behaviors, optimize seasonal inventory, and forecast future sales for strategic decision-making.



**DATASET**

Sourced from Kaggle.

Dataset Link: https://www.kaggle.com/datasets/terencekatua/retail-sales-dataset/data



**ANALYTICS WORKFLOW**



* Data Processing: Verified financial integrity and engineered demographic cohorts.



* Exploratory Data Analysis: Tracked Month-over-Month growth and identified high-value customer segments.



* Predictive Analytics: Deployed Facebook Prophet for a 90-day sales forecast.



* Visualization: Built an interactive Streamlit dashboard using Plotly.



**KEY BUSINESS INSIGHTS**



* Revenue Drivers: Identified top-grossing product categories and key demographics.



* Transaction Behavior: Analyzed average order value (AOV) and volume trends.



* Future Projections: Mapped 90-day revenue trends to optimize marketing and inventory.



**TECH STACK**



* Python



* Pandas



* Plotly



* Prophet



* Streamlit
